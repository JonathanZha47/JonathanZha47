## About Me

I am a first-year PhD student at **[VUSec](https://www.vusec.net/), Vrije Universiteit Amsterdam**, supervised by **Min Chen** and **Herbert Bos**.

I work on the safety of **AI agents**: language models that no longer only answer but act, editing files, running commands, and operating browsers and phones. I look for **new attack surfaces where agents are actually deployed**: the context, memory, and harness around the model, tool and multi-agent handoffs, and the screens that GUI agents read. Finding an attack or proposing a defense is not enough. I also want to understand *why* the failure happens, using **mechanistic interpretability** to trace how an agent breaks a rule and to build monitors that catch it before it acts.
